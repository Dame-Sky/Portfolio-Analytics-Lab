### 📘 Portfolio Analytics Lab — Glossary of Terms

This glossary defines financial, statistical, and system-specific terms used throughout Portfolio Analytics Lab.

The goal is clarity, not jargon.

## 🔁 Portfolio Construction & Accounting
**Transaction**

A single financial event affecting the portfolio (e.g. BUY, SELL, DIVIDEND, FUNDSIN).

Transactions are the source of truth in Portfolio Lab.

**Holdings**

The quantity of each instrument held at a specific point in time, reconstructed from transactions.

Holdings are derived, never entered directly.

**Cost Basis**

The cumulative acquisition cost of a holding, adjusted for corporate actions.

Used for reporting, not performance measurement.

**Corporate Actions**

Non-trade events that affect holdings (e.g. splits, buybacks, capital returns).

Handled explicitly by the holdings engine.

**External Cash Flow**

Cash entering or leaving the portfolio that is not generated by market movement
(e.g. deposits, withdrawals).

Critical for correct performance calculation.

## 💰 Valuation & Returns
**Market Value**

The current monetary value of a holding:

Quantity × Price × FX Rate

**FX Normalization**

The process of converting all values into a common base currency (JMD).

Ensures comparability across assets.

**Simple Return**

A basic percentage change in value over a period.

Used internally but not sufficient for portfolios with cash flows.

**Time-Weighted Rate of Return (TWRR)**

A performance measure that removes the impact of external cash flows.

Industry standard for portfolio manager evaluation.

**Money-Weighted Rate of Return (MWRR / IRR)**

A return measure that accounts for both timing and size of cash flows.

Reflects the investor’s actual experience.

**Sub-Period Return**

A return calculated between two cash-flow events.

These are chain-linked to compute TWRR.

## 📊 Performance Attribution
**Attribution**

The process of explaining where returns came from, not just how much was earned.

**Benchmark**

A reference portfolio or index used for comparison.

Attribution is always relative to a benchmark.

**Brinson-Hood-Beebower (BHB) Model**

An attribution framework that decomposes excess return into:

- Allocation effect
- Selection effect
- Interaction effect

**Brinson-Fachler (BF) Model**

A refined attribution model that adjusts selection effects for benchmark returns.

Often preferred for professional reporting.

**Allocation Effect**

Return impact from over- or under-weighting sectors relative to the benchmark.

**Selection Effect**

Return impact from security choice within a sector.

**Interaction Effect**

The combined impact of allocation and selection decisions.

**Alpha**

The portion of return not explained by benchmark exposure.

In regressions, alpha is the intercept term.

## ⚖️ Risk & Diversification
**Volatility**

A statistical measure of return variability.

Typically annualized.

**Correlation**

A measure of how asset returns move relative to each other.

Used to understand diversification.

**Covariance Matrix**

A matrix describing how all asset returns vary together.

Foundation of portfolio risk modeling.

**Diversification Ratio**

The ratio of weighted asset volatility to portfolio volatility.

Higher values indicate better diversification.

**Value-at-Risk (VaR)**

An estimate of the maximum expected loss over a given horizon at a given confidence level.

Example:
“99% daily VaR of J$2,000” means losses should exceed J$2,000 only 1% of the time.

**Marginal VaR**

The sensitivity of portfolio VaR to a small change in an asset’s weight.

**Component VaR**

The contribution of each asset to total portfolio VaR.

## 📈 Market Exposure & Regression Analysis
**Excess Return**

Return above the risk-free rate.

Used to isolate compensation for risk.

**Risk-Free Rate**

The theoretical return of a riskless investment.

Used as the baseline in performance and regression analysis.

**Regression**

A statistical method used to estimate relationships between portfolio returns and external factors.

**Market Beta**

Measures sensitivity of portfolio returns to market movements.

- β ≈ 1 → market-like
- β > 1 → amplified exposure
- β < 1 → defensive exposure

**FX Sensitivity**

Measures how portfolio returns respond to currency movements.

**R-Squared (R²)**

The proportion of return variability explained by the regression model.

Low R² is common in real portfolios.

**F-Statistic**

Tests whether the regression model explains returns better than chance.

**P-Value**

Measures statistical confidence in a coefficient.

Lower values indicate stronger evidence of a relationship.

**Residuals**

The portion of returns not explained by the model.

Reflect idiosyncratic behavior and noise.

**Jensen’s Alpha**

Residual performance after accounting for factor exposures.

## 🛡️ Model Diagnostics
**Durbin–Watson Statistic**

Tests for autocorrelation in regression residuals.

Values near 2 indicate healthy independence.

**Condition Number**

Measures numerical stability and multicollinearity in regressions.

Very high values suggest unstable coefficients.

**Normality Tests**

Statistical checks on residual distribution shape.

Minor deviations are expected in financial data.

## 🧩 System & Architecture Terms
**Engine**

A self-contained module responsible for one financial domain
(e.g. returns_engine, risk_engine).

**Deterministic System**

A system where identical inputs always produce identical outputs.

Portfolio Lab is deterministic by design.

**Auditability**

The ability to trace any result back through each computational layer.

**In-Memory Processing**

Data is processed during the session and destroyed afterward.

No user data persistence.

**Analytics Sandbox**

An environment for exploration and learning, not trading or advice.

## 📌 Final Note

Portfolio Analytics Lab intentionally favors:

- transparency over opacity
- interpretation over prediction
- structure over shortcuts

This glossary exists to support that philosophy.
